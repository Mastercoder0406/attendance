## Looked at and decided it was fine

- Endpoints are plain `def`, If a blocking driver is used inside an async `def` function, it pauses the entire FastAPI event loop, completely destroying concurrency for other incoming requests. FastAPI automatically handles standard def endpoints by offloading them to an internal thread pool, ensuring that blocking database calls do not freeze the application. I kept them as `def` on the sane purpose.

- By default, `load_dotenv()` acts as a fallback mechanism. It loads local `.env` files for development convenience but respects pre-existing system environment variables.

- When calling insert_one(document), PyMongo modifies the input dictionary in place by injecting a BSON `_id` field. To prevent unexpected side effects or payload corruption, we decouple our raw application data from database-mutated objects using clean copies and dedicated serializers rather than stripping elements destructively.

- MongoClient is a lazy operation. PyMongo does not immediately perform a network handshake or block process startup. The actual connection pool is established only when the first database command executes. This ensures the FastAPI server starts reliably and survives initial container startup races, even if the MongoDB cluster is momentarily slow to respond.
